# ⚜️ Империум Линк — мессенджер Империи Гиперион

Официальное средство связи цифрового государства **Империя Гиперион**.
Киберпанк + имперский неоклассицизм: чёрно-синяя цитадель, золотые акценты,
Playfair Display для указов, Inter для посланий.

> Репозиторий: https://github.com/Hyperion612/Messenger_Imperium-Link

## ✦ Возможности

- **Врата цитадели** — вход по Гиперион-ID (`HIT-XXXXX`), двухфакторная аутентификация,
  восстановление пароля через почту, сессии с истечением срока (24 ч).
- **Государственные каналы** — только официальные каналы Империи (read-only для граждан):
  - 👑 **Слово Императора** — указы и повеления
  - 📜 **Вестник Закона** — системные уведомления о законах
  - 🏛 **Рынок Гипериона** — товары и услуги Империи
  - 🏛 **Сенат Империи** — официальные решения Сената
- **Панель Администратора** — доступна только СЕНАТОРАМ и ИМПЕРАТОРУ:
  - Управление гражданами (просмотр, изменение рангов)
  - Управление каналами (просмотр, статистика)
  - Статистика Империи (количество граждан, каналов, сообщений, онлайн)
- **Поиск** — по сообщениям, каналам и гражданам, фильтры по типу и дате.
- **Реальное время** — симуляция WebSocket-канала: присутствие граждан,
  входящие указы и законы от Императора, push-уведомления, звуки.
- **Ранги Империи** — НОВИЧОК → ГРАЖДАНИН → СТРАЖ → ОФИЦЕР → ГЕНЕРАЛ → СЕНАТОР → ИМПЕРАТОР,
  привилегии gated по рангу (админ-панель — только для СЕНАТОРА и ИМПЕРАТОРА).
- **Имперские функции** — ИИ-ОКО (модерация запрещённых слов), Уровень Света
  (Искра → Вечное Пламя), награды за активность, переводы HYPER через Казначейство,
  покупки на Рынке.
- **PWA** — установка на устройство, оффлайн-кэш, manifest + service worker.

## 🚀 Запуск

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # production-сборка в dist/
```

| Поле | Значение |
|---|---|
| Гиперион-ID | `HIT-77777` |
| Пароль | `hyperion` |
| 2FA-код | отображается в push-уведомлении на экране (демо) |
| Ранг | СЕНАТОР (доступ к админ-панели открыт) |

## 📁 Структура

```
src/
  App.tsx            каркас: рейл Империи, слои фона, мобильная навигация
  main.tsx           вход + регистрация service worker (PWA)
  types.ts           доменная модель: Citizen, Chat, Message, Rank…
  store.tsx          состояние, действия, WebSocket-симуляция, звук, localStorage
  icons.tsx          40+ кастомных SVG, Имперская печать, лавровые ветви
  index.css          тема Империи, анимации, glass-слои
  data/seed.ts       граждане, чаты, история, указы, рынок, реплики ботов
  components/
    Login.tsx        врата цитадели: вход, 2FA, восстановление пароля
    Sidebar.tsx      список государственных каналов, фильтры
    ChatView.tsx     сообщения (read-only для граждан), указы, законы
    AdminPanel.tsx   панель администратора (граждане, каналы, статистика)
    Overlays.tsx     профиль/казначейство/рынок/поиск/жалобы
.github/workflows/pages.yml   автодеплой на GitHub Pages
public/              manifest.webmanifest, sw.js
```
