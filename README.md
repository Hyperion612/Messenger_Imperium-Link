# ⚜️ Империум Линк — мессенджер Империи Гиперион

Официальное средство связи цифрового государства **Империя Гиперион**.
Киберпанк + имперский неоклассицизм: чёрно-синяя цитадель, золотые акценты,
Playfair Display для указов, Inter для посланий.

> Репозиторий: https://github.com/Hyperion612/Messenger_Imperium-Link

## ✦ Возможности

- **Чистый мессенджер** — без предустановленных чатов. Пользователи создают чаты сами или через главный пульт Императора.
- **Врата цитадели** — вход по Гиперион-ID (`HIT-XXXXX`), двухфакторная аутентификация, восстановление пароля через почту, сессии с истечением срока (24 ч).
- **Создание чатов** — личные (1-на-1), групповые (до 1000 участников), каналы (неограниченная подписка).
- **Сообщения** — текст с эмодзи, фото, документы, голосовые (запись + волновой плеер), ответы, пересылка, редактирование (окно 5 минут), удаление с пометкой, галочки ✓ / ✓✓.
- **Панель Администратора** — доступна только СЕНАТОРАМ и ИМПЕРАТОРУ:
  - Управление гражданами (просмотр, изменение рангов)
  - Управление каналами (просмотр, статистика)
  - Статистика Империи (количество граждан, каналов, сообщений, онлайн)
- **Поиск** — по сообщениям, каналам и гражданам, фильтры по типу и дате.
- **Реальное время** — симуляция WebSocket-канала: присутствие граждан, push-уведомления, звуки.
- **Ранги Империи** — НОВИЧОК → ГРАЖДАНИН → СТРАЖ → ОФИЦЕР → ГЕНЕРАЛ → СЕНАТОР → ИМПЕРАТОР, привилегии gated по рангу (админ-панель — только для СЕНАТОРА и ИМПЕРАТОРА).
- **Имперские функции** — ИИ-ОКО (модерация запрещённых слов), Уровень Света (Искра → Вечное Пламя), награды за активность, переводы HYPER через Казначейство, покупки на Рынке.
- **PWA** — установка на устройство, оффлайн-кэш, manifest + service worker.

## 🌐 Интеграция с государством Империя Гиперион

Мессенджер интегрирован с основным порталом государства [Империя Гиперион](https://hyperion612.github.io/Imperium_Hyperion/).

### Кнопка "Для разработчиков"
На главной странице (экран ожидания) доступна кнопка **"Для разработчиков"**, которая открывает страницу интеграции с государством.

### Функции интеграции:
- **Единый профиль гражданина** — синхронизация ID, ранга, Уровня Света и баланса HYPER
- **Общие государственные каналы** — доступ к официальным каналам Империи
- **Синхронизация данных** — передача чатов, сообщений и статистики в Казначейство
- **API эндпоинты**:
  - `GET /api/citizen/:id` — получение данных гражданина
  - `POST /api/sync` — синхронизация данных мессенджера
  - `PATCH /api/citizen/:id/balance` — обновление баланса HYPER
  - `PATCH /api/citizen/:id/light` — обновление Уровня Света

### Подключение:
1. Нажмите **"Для разработчиков"** на главной странице
2. Введите ваш Гиперион-ID (формат HIT-XXXXX)
3. Нажмите **"Подключиться к Империи"**
4. После успешного подключения нажмите **"Синхронизировать с государством"**

Все данные будут синхронизированы с основным порталом государства.
