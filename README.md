# Империум Линк 🏛

**Государственный мессенджер цифрового государства «Империя Гиперион»**

Единая система связи Империи: личные послания, собрания (группы до 1000 участников), вещательные каналы, комнаты провинций, казначейские переводы HYPER, имперский рынок, система рангов, привилегий и Уровня Света.

---

## Быстрый старт

```bash
npm install     # установка зависимостей
npm run dev     # локальная разработка (Vite)
npm run build   # производственная сборка → dist/
```

Данные входа (демо-гражданин):

| Поле | Значение |
| --- | --- |
| ID гражданина | `HIT-77777` |
| Пароль | любой непустой (от 4 символов) |
| Двухфакторный код | показывается в push-уведомлении прямо на экране |

Восстановление пароля: вкладка «Забыли пароль?» → email → «перехват кода» (демо).

## Возможности

- **Аутентификация** — вход по Гиперион-ID (HIT-XXXXX), 2FA, восстановление пароля, сессии с истечением (24 ч), список активных сессий.
- **Чаты** — личные, группы, каналы (read-only), автоматические комнаты 4 провинций, закрепление, архив, «без уведомлений».
- **Сообщения** — текст, эмодзи-панель, изображения, документы, голосовые (запись → волна → воспроизведение), ответы, пересылка, редактирование (окно 5 минут), удаление с пометкой, статусы доставки ✓ / ✓✓, индикатор «печатает…».
- **Реальное время** — симуляция WebSocket-шины: входящие сообщения, смена присутствия граждан (онлайн / недавно / оффлайн), живые чаты провинций, указы Императора и законы Сената.
- **Поиск** — по сообщениям, чатам и гражданам; фильтры по типу (текст/фото/файлы/голосовые/переводы) и дате; подсветка совпадений.
- **Уведомления** — push-тосты, звуковые сигналы (WebAudio), упоминания `@имя`, индивидуальные настройки на чат.
- **Безопасность** — E2E-пометка личных переписок, ИИ-ОКО (фильтр запрещённых слов с блокировкой отправки), жалобы Страже, модерация указов.
- **Имперская экономика** — баланс HYPER, переводы через чат (Казначейство, пошлина 0%), рынок с покупками, гранты Сената.
- **Прогрессия** — Уровень Света (Искра → Факел → Заря → Сияние → Вечное Пламя), награды за активность, ранги: НОВИЧОК → ГРАЖДАНИН → СТРАЖ → ОФИЦЕР → ГЕНЕРАЛ → СЕНАТОР. Создание групп — с ГРАЖДАНИНА, каналов — с ОФИЦЕРА.
- **PWA** — манифест, оффлайн-кэш (service worker, network-first), установка на устройство; localStorage-персистентность профиля, чатов и сообщений.

## Стек

- **Frontend:** React 18 + TypeScript + Vite + Tailwind CSS v4
- **Дизайн:** киберпанк × имперский неоклассицизм; Playfair Display / Inter; чёрно-синий `#0a0a20` + золото `#FFD700` + серебро `#C0C0C0`; glassmorphism, живой фон (сетка, угли, свечение)
- **Хранение:** localStorage (оффлайн-режим); архитектура готова к подключению REST + Socket.io + PostgreSQL + Redis + S3

## Структура

```
src/
├── main.tsx               # точка входа
├── App.tsx                # каркас: рейл навигации, мобильная панель, фон
├── store.tsx              # состояние, действия, WebSocket-симуляция, звук
├── types.ts               # доменные типы
├── icons.tsx              # кастомные SVG-иконки и Имперская печать
├── index.css              # тема Империи, анимации, glass-слои
├── data/seed.ts           # граждане, чаты, история, указы, рынок, реплики
└── components/
    ├── Login.tsx          # вход, 2FA, восстановление пароля
    ├── Sidebar.tsx        # список чатов, фильтры, контекстное меню
    ├── ChatView.tsx       # сообщения, композер, голосовые, эмодзи
    └── Overlays.tsx       # профиль, поиск, казначейство, рынок, жалобы
```
